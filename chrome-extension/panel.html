模型與設定

設定保存在這台電腦的 Chrome 擴充功能儲存空間。

01 / 本機語音辨識

音訊留在本機 GPU；更換後重新開始擷取。

日文只是預設，可選其他語言或自動偵測。自動偵測短句可能不準確。

有助於專有名詞辨識，不能保證不會聽錯。

02 / 直播翻譯 API

處理語音辨識後的文字；模型名稱可以直接修改。

03 / 留言助手 API

讀取留言與回覆翻譯都使用這組設定，不影響直播字幕。

聊天模型可套用習慣；Riva 專用翻譯模型不支援風格提示。

04 / 影片上的字幕

大小可輸入 12–96 px，全螢幕隨畫面放大。Web 套用於觀看區；擴充功能套用於 YouTube 影片。完整文字保留於本機轉錄。

擴充功能將畫面與聲音一起延後，讓翻譯有時間完成。更換後重新開始擷取。較長延遲會降低緩衝畫質。

05 / 影片現有字幕翻譯

整份字幕自動以最多 40 句／12,000 字分批，保留時間與上下文。獨立模型只處理現有字幕；目標語言沿用「字幕翻譯成」。載入不呼叫 API，按開始才翻譯。

API Key 僅存於此瀏覽器；不會寫入專案檔案。

金鑰儲存空間沒有加密；只傳送到本機服務，再由本機服務呼叫你指定的 API。Web 與擴充功能分別保存設定。
