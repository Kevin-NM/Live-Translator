# 2026-09-25 重建紀錄

## 改動

使用者將舊版專案移走，明確要求從零重做。舊版追蹤檔案在工作樹中顯示刪除；這是使用者有意移走，勿還原。新建本機 FastAPI 服務、純網頁 Chrome 分頁音訊擷取、AudioWorklet 16 kHz PCM16 降採樣、faster-whisper 日文辨識、翻譯 API 客戶端、音檔 CLI、模型下載腳本、啟動與安裝腳本。

## 檔案與決策

- `app/stt.py` 固定從專案內 `models/faster-whisper-large-v3-turbo/` 載入模型，CUDA float16，日文，beam size 1。不隱式下載模型。
- `app/main.py` 提供 WebSocket 串流字幕、手動文字翻譯、模型狀態。暫定字幕可覆蓋；定稿後才呼叫翻譯 API。最多 6 秒自動分段。
- `app/translation.py` 支援 NVIDIA Build、OpenAI `/v1/chat/completions`、自訂相容端點。API Key 不寫入檔案。
- `web/` 是不需要建置工具的操作頁。Chrome 由使用者分享分頁音訊。
- `models/`、`.venv/` 以 `.gitignore` 排除，但模型實際放於專案目錄內。

## 驗證與目前狀態

模型完整下載至專案內（`model.bin` 1,617,884,929 bytes，另有 config、tokenizer、preprocessor、vocabulary），模型 revision 固定為 `0a363e9161cbc7ed1431c9597a8ceaf0c4f78fcf`。在 RTX 4060 Laptop GPU 上成功以 CUDA float16 載入。用 Edge TTS 產生的測試日文「こんにちは。今日は新しいゲームを紹介します。よろしくお願いします。」進行音檔辨識，逐句輸出正確。相同音訊轉成 16 kHz PCM16 後送入真實 WebSocket/GPU 管線，得到 partial 與三段 final，內容也正確。`python -m unittest discover -s tests -v` 的三項測試通過。`setup.ps1` 在此機器執行成功；`run.py` 的啟動流程、FastAPI 服務與 `/api/status` 正常；Chrome 頁面及三種翻譯服務選單已檢查。

Python 3.12 全新 venv 的 PyAV 大檔下載卡住，已停掉並改用此機器已有依賴的 Python 3.10 system-site-packages venv；`requirements.txt` 固定到實測版本。一般新環境仍須按 `setup.ps1` 下載相同依賴。瀏覽器的 `getDisplayMedia` 分享挑選視窗無法由此 UI 自動化完整選取，因此尚未驗證真正的 Chrome 分頁擷取。翻譯 API 沒有使用者金鑰，因此尚無法端到端驗證 NVIDIA 或 OpenAI。聊天室目前只支援手動貼上與複製；自動擷取留言與回填聊天室、個人風格學習仍未做。
