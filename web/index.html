本機字幕服務已啟動

操作介面現在是 Chrome 擴充功能。字幕會顯示在 YouTube 影片上。

  1. 在 Chrome 開啟 chrome://extensions，開啟「開發人員模式」。
  2. 點「載入未封裝項目」，選取專案中的 chrome-extension 資料夾。
  3. 開啟 YouTube 影片，點擴充功能圖示。側邊欄的「設定」可儲存 API Key，並測試 NVIDIA、OpenAI 或自訂 API。
  4. 回到「字幕」按「開始擷取目前分頁」。字幕會疊在影片上。結束時按「停止」，並關閉啟動服務的命令視窗。
